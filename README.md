# SamLek Furniture Website

A modern, responsive furniture company website built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. The website showcases the company's services, products, craftsmanship, and provides customers with an easy way to request furniture quotations through WhatsApp.

##  Features

- Modern responsive design
- Multi-page navigation with React Router
- Beautiful hero sections
- About page
- Products showcase
- Contact page
- WhatsApp quotation form
- Professional footer with social media links
- Scroll-to-top functionality
- Mobile-friendly navigation
- Optimized for desktop, tablet, and mobile devices

##  Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React
- React Icons

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/samlek-furniture.git
```

Navigate into the project:

```bash
cd samlek-furniture
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

##  Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 🌐 Deployment

This project is optimized for deployment on **Vercel**.

It includes a `vercel.json` configuration to support client-side routing with React Router.

## 📱 Contact Form

The contact form redirects customers to WhatsApp with a pre-filled message containing their contact information and enquiry.
